# Flood Inundation Mapping — Embakasi, Nairobi (2026)

## Overview
This project maps flood inundation using Sentinel-1 SAR data processed in Google Earth Engine.

## Study Area
Embakasi Sub-County, Nairobi, Kenya

## Methodology
1. Data acquisition (Sentinel-1 SAR)
2. Preprocessing (speckle filtering)
3. Change detection (ratio & difference)
4. Thresholding
5. Refinement:
   - Permanent water removal
   - Slope masking
   - Morphological filtering
6. Area calculation and export

## Results
- Total Area: 17.55 km²
- Flooded Area: 0.65 km²
- Flood Percentage: 3.73%

## Tools
- Google Earth Engine
- ArcMap

## Data Sources
- Sentinel-1 SAR (ESA)
- JRC Global Surface Water
- SRTM DEM
